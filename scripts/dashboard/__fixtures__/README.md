# Dashboard builder fixtures

Test fixtures for the dashboard graph builder. Two hard rules:

1. **Neutral placeholder content only.** No slug, name, path, or domain from
   any real user project may appear here - use invented names like
   `sample-cycle`, `widget-panel`, `example.com`.
2. Fixtures model *shapes*, not projects: malformed frontmatter,
   missing fields, sentinel values, and polymorphic link forms are the
   point.
